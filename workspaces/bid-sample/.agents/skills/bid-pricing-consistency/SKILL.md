# 报价一致性

用于核对**报价一致性**这一类判据。判据本身写在标书目录的判据文件里（默认 `评审条件.md`）——本技能只说怎么查，
不说要求是什么。开工前先读判据文件，并在每条结论的 `basis` 里引用具体条目；扩展会把判据文件的指纹记进本轮 run 头。

## 怎么核对

总价与明细、大小写、不同表处出现的同一金额是否自洽

## 边界与反例

把报价明细逐行相加与总价比对；核对大写与小写金额；核对开标一览表、报价明细表、承诺函里的金额是否一致；核对单位与币种

## 输出要求

分项含税与不含税混用（要对齐口径再比）；金额一致但单位写错（按不一致记，不放过）；合计四舍五入差异在判据允许范围内时不记为问题|结论写清差异的方向与金额，并给出两个出处的位置。结论用 `bid_record_findings` 提交，必填 `verdict`；不是"满足"的必须写 `problem`。
判据文件缺失时用本技能的通用做法，并在结论里显式说明用的是通用判据。
