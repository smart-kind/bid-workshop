# 格式与形式合规

用于核对**格式与形式合规**这一类判据。判据本身写在标书目录的判据文件里（默认 `评审条件.md`）——本技能只说怎么查，
不说要求是什么。开工前先读判据文件，并在每条结论的 `basis` 里引用具体条目；扩展会把判据文件的指纹记进本轮 run 头。

## 怎么核对

签章、装订、份数、格式要求是否符合判据文件的形式条款

## 边界与反例

按判据文件的形式清单逐条核对：签字、盖章、骑缝、目录页码、份数、密封要求

## 输出要求

盖章在复印件上不算有效签章；电子签章要看判据是否接受；页码错位属于形式问题但不影响内容评审，严重度按判据文件定|结论写清不符的具体形式要求与其在文件中的位置。结论用 `bid_record_findings` 提交，必填 `verdict`；不是"满足"的必须写 `problem`。
判据文件缺失时用本技能的通用做法，并在结论里显式说明用的是通用判据。
