# 技术方案响应

用于核对**技术方案响应**这一类判据。判据本身写在标书目录的判据文件里（默认 `评审条件.md`）——本技能只说怎么查，
不说要求是什么。开工前先读判据文件，并在每条结论的 `basis` 里引用具体条目；扩展会把判据文件的指纹记进本轮 run 头。

## 怎么核对

方案是否逐条响应判据文件里的技术条款，是否有偏离或漏项

## 边界与反例

把判据文件的技术条款逐条编号，在方案里找到对应章节；无对应即为漏项；有对应但参数低于要求即为负偏离

## 输出要求

提供了类似案例不等于响应了本条；参数高于要求但未说明实现的，记为需澄清而不是不满足；引用外部标准时要核对版本号|结论写清条款号、响应位置、偏离方向。结论用 `bid_record_findings` 提交，必填 `verdict`；不是"满足"的必须写 `problem`。
判据文件缺失时用本技能的通用做法，并在结论里显式说明用的是通用判据。
