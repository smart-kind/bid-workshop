# 资质与主体资格

用于核对**资质与主体资格**这一类判据。判据本身写在标书目录的判据文件里（默认 `评审条件.md`）——本技能只说怎么查，
不说要求是什么。开工前先读判据文件，并在每条结论的 `basis` 里引用具体条目；扩展会把判据文件的指纹记进本轮 run 头。

## 怎么核对

营业执照、资质证书、业绩、授权文件是否齐全且与投标主体一致

## 边界与反例

逐项对照判据文件的资质清单，核对证书编号、有效期、主体名称是否与投标人一致；业绩核对合同名称、金额、时间

## 输出要求

证书过期但仍附在标书中（不是缺失而是失效，结论要分开写）；分公司资质不能当作母公司资质；复印件模糊到无法辨认编号时按无法核对处理|每条结论写清：缺哪一项、判据文件里的第几条、定位到哪一段。结论用 `bid_record_findings` 提交，必填 `verdict`；不是"满足"的必须写 `problem`。
判据文件缺失时用本技能的通用做法，并在结论里显式说明用的是通用判据。
