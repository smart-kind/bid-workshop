# 业务技能包：分工与使用

四个技能分别对应四类判据。它们**不说"要求什么"**——要求写在标书目录里的判据文件（默认 `评审条件.md`）；
技能只说**"怎么查"**：核对的动作、边界与反例、以及结论怎么写。

使用纪律：

- 每个结论的 `basis` 必须引用判据文件里的具体条目，并带上判据文件的版本（扩展会把判据文件的指纹记进本轮 run 头）。
- 判据文件与技能冲突时，**以判据文件为准**：技能是通用做法，判据是本项目的要求。
- 判据文件缺失时，用技能自带的通用判据，并在结论里**显式说明用的是通用判据**，不要静默替换。
- 定位到具体段落（`blockIndex`）才写批注；落在表格里的按降级规则锚到表格上方并注明行列。
