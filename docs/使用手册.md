# Bid Workshop 使用手册

这是一份**照着做就行**的手册。每一步都写清楚了点哪里、应该看到什么。
不涉及改代码，也不假设你懂这个项目内部是怎么搭的。

> 关于界面语言：窗口最上面那条菜单栏是**英文**的（`File` / `Open Folder…` / `Save Document`），
> 文档里的功能区标签是**中文**的（`文件` / `开始` / `审阅`…）。
> 这是现状，不是你的设置错了 —— 下面每一处我都在标签后面注明了它长什么样。

---

## 1. 打开它

在项目目录里执行：

```bash
./start-dev.sh
```

第一次会先构建一遍，慢一点，之后就是几十秒。窗口弹出来就成功了。

- 想关掉：直接关窗口，或者回终端按 `Ctrl+C`。
- 想在别人的机器上跑：先把仓库复制过去，`pnpm install`，再 `./start-dev.sh`。
  不需要额外的服务、数据库、密钥。

---

## 2. 窗口里有什么

打开之后先别急着点，看一眼布局：

| 位置               | 是什么                                                         |
| ------------------ | -------------------------------------------------------------- |
| **左边一窄列**     | 会话列表。你每开一个话题就是一条，可以理解成「每一次找人干活」 |
| **左下角一排标签** | `Files`（文件）、`Review`（评审）、`Terminal`（终端）三块面板  |
| **右边一大块**     | 平时是**对话**；一旦打开文档，就变成**文档**                   |

这一节你只需要记住一句：**文档是从左下角 `Files` 面板里点出来的。**

---

## 3. 打开一个文件夹（工作区）

菜单栏 → `File` → `Open Folder…`（快捷键 `⌘O`）。

选中仓库里的这个目录：

```
workspaces/bid-sample
```

里面是准备好的样例数据：一份真实的投标文件 `.docx`、一份评审条件 `.md`。

选完之后，左下角 `Files` 面板里就能看到这些文件了。

> 这个「文件夹」就是你的**工作区**。软件里的一切都以它为中心：
> AI 干活、文件树、评审，都是针对当前这个文件夹的。

---

## 4. 打开那份 Word 文档

在 `Files` 面板里，点一下：

```
投标文件-某软件科技.docx
```

右边立刻变成文档视图 —— 页面、页边距、分页、页码都按真实排版渲染，不是「预览图」。

**这是打开文档唯一稳的路：文档得在当前工作区里。**
想开别处的文档，就用 `File` → `Open Folder…` 把它的文件夹打开，然后再点它。

> 两个容易踩的坑：
>
> - `⌘O` 是**打开文件夹**（`File` → `Open Folder…`），不是打开文档。
> - 软件一次只显示**一份**文档。换文档就再点一个文件。

---

## 5. 改一句话

1. 直接在页面上点进一行字，像用 Word 一样打字。
2. 改完存盘：`⌘S`，或者菜单 `File` → `Save Document`。
3. 想存成另一个文件：`⌘⇧S`（`File` → `Save Document As…`）。

**怎么确认真的存进去了**：切到别的文件再切回来，改动还在。
（真实情况是它已经写进磁盘上的那个 `.docx` 了 —— 用 Word 打开同一个文件也能看到。）

---

## 6. 留下审阅痕迹 —— 这是这个软件存在的理由

在文档功能区里点 **`审阅`** 标签（和 Word 一样在 `开始` / `插入` 后面那一排）。这一页里有三类东西：

**修订**
点一下「修订」就打开了记录。之后你做的每一处改动都会变成修订：

- 插入的文字带下划线
- 删除的文字带删除线

**批注**
先**用鼠标选中一句话**，再点「新建批注」。选中的那句话就是批注挂靠的位置。

**接受 / 拒绝**
可以一条一条来（「接受此修订」「拒绝此修订」），也可以「接受所有修订」「拒绝所有修订」。

**关键一点：这些东西不是画在屏幕上的。**
存盘之后，批注和修订是**真的写进那份 `.docx` 文件**里的。用 Word 打开同一份文件，
批注还在、修订还在、谁也还在。这才是「交出去」的前提。

---

## 7. 把它交出去

- **导出 PDF** / **导出 HTML**：文档界面里可以导出成文件，导出的是你看到的排版。
- **打印**：**不支持**。这台机器上没接系统打印。
- **把好几份 PDF 合成一份**：**不支持**，仓库里没引入 PDF 相关的库。

导出完的文件在哪，界面会告诉你路径。

---

## 8. 从零写一份新文档

菜单 `File` → `New Document`（快捷键 `⌘⌥N`）。

它会把当前视图**清成一张白纸**（不是新开一个窗口），你直接开始写就行。
写完 `⌘S`，会问你要存到哪儿。

---

## 9. 让 AI 干活 —— 有两条路，别混

这个软件里有**两套** AI 入口，能力不一样，我先说清楚再让你用。

### 9.1 壳自己的 AI（左边的对话）

就是你平时打字聊天的那块。你直接说人话：

> 读一下 `投标文件-某软件科技.docx`，把第 12 段的金额改成 30 万

它会**真的去改磁盘上的那个文件**。它手上有四个文档工具：

| 工具           | 干什么                             |
| -------------- | ---------------------------------- |
| `read_docx`    | 读一份 `.docx`，把段落按编号列出来 |
| `create_docx`  | 从零写一份新的 `.docx`             |
| `update_docx`  | 改某一段、或者在某个位置插一段     |
| `comment_docx` | 给某一段（或者段里的某句话）加批注 |

你不需要记这些名字，直接提要求就行；它自己会挑。

前提：**得先有工作区**（第 3 步），因为工具说的是「相对于这条会话的文件夹」。

### 9.2 文档里自带的 AI 面板（文档右侧那一栏）

打开文档后，右边会有一栏 AI 面板。它跟上面那套是**两回事**：

- 它专门改**你正在看的这份文档**：插入、替换、加批注、接受/拒绝修订，都在编辑器里实时发生。
- 它用的是**你在 pi 里配好的模型**（也就是 `~/.pi/agent/models.json` 里那几个）。
  这里不需要单独再配一遍 —— 一个软件只有一处配模型的地方。
- 如果还没配过模型，你发一句话，它会**明确报错**告诉你没有配置 AI 服务
  （原文是一句英文：`No AI provider is configured for this app yet.`），
  不会假装转圈、也不会让你以为是自己操作错了。

文档里还有一些一键的 AI 动作，比如「AI 总结修订」「AI 处理批注」，
就在 `审阅` 那一页里，把一批修订或批注丢给它总结/处理。

---

## 10. 遇到这些，别慌

| 现象                             | 其实是什么                                                    |
| -------------------------------- | ------------------------------------------------------------- |
| 点了文档没反应                   | 文档不在当前工作区。先 `File` → `Open Folder…` 打开它的文件夹 |
| `⌘O` 打开了选文件夹              | 对，它就是打开文件夹，不是打开文档                            |
| AI 说「还没有配置 AI 服务」      | 模型没配。配好 `~/.pi/agent/models.json` 再试                 |
| 想打印                           | 不支持                                                        |
| 想合并 PDF、从磁盘挑一张图插进来 | 不支持                                                        |
| 只能看一份文档                   | 一窗一份，这是当前的设计                                      |

---

## 11. 一轮完整的演示（照着走一遍就懂了）

1. `./start-dev.sh`，等窗口出来。
2. 菜单 `File` → `Open Folder…`，选 `workspaces/bid-sample`。
3. 左下角 `Files` 面板里点 `投标文件-某软件科技.docx`，右边出现文档。
4. 点 `审阅` → 打开「修订」→ 在正文里改一句话 → `⌘S`。
5. 还是 `审阅` 页 → 选中一句话 → 「新建批注」→ 写上你想说的话 → `⌘S`。
6. 导出一次 PDF，看导出的排版对不对。
7. 回到左边开一个新的会话，跟壳的 AI 说：
   「读一下 `投标文件-某软件科技.docx`，告诉我它一共有几段，第 3 段写了什么。」
8. 在文档右侧的 AI 面板里问一句关于这份文档的话（前提是模型配好了）。
9. 关掉窗口，或者终端 `Ctrl+C`。

走完这一遍，你就把这个壳**现在真正会做的事**都摸过一遍了。
